CourseLLM Quiz Service

AI-Powered Adaptive Assessment System

Technical Report | CourseLLM Learning Platform | 2026

Executive Summary

The Quiz Service is a microservice within the CourseLLM platform that provides intelligent, AI-powered assessment capabilities. It leverages Google's Gemini AI through Firebase Genkit to dynamically generate personalized quizzes, evaluate student responses with detailed feedback, and continuously update student learning trajectories based on performance.

Core Capabilities

🎯 Dynamic Quiz Generation

AI generates unique questions based on course learning objectives. Supports custom prompts for focused assessments.

🤖 Intelligent Grading

Multi-modal grading: instant scoring for multiple choice, AI evaluation (0-10 scale) for free-text responses.

📈 Learning Trajectory

Automatic mastery updates per learning objective. Tracks progress history with reasoning.

💾 Persistent Results

All quiz data stored in Firestore with full audit trail for student profiles.

Technical Highlights

  • Server Actions: All operations run server-side for security
  • Type Safety: Full TypeScript with Zod schema validation
  • Structured Output: Genkit ensures AI returns valid JSON
  • Authorization: User ownership verified before grading
  • Atomic Updates: Firestore transactions for data integrity
  • Timestamp Serialization: Proper handling for client hydration
  • Fallback Data: Mock data support for development mode
  • Custom Prompts: Student-specified focus areas for quizzes

Firestore Data Model

📝 quizzes/{quizId}

Quiz document with questions, answers, status, scores, feedback, and LO mappings.

👤 users/{uid}/quizResults

Subcollection storing completed quiz results with scores and AI feedback.

📊 users/{uid}/skills

Learning objective mastery levels with history of changes and reasoning.
